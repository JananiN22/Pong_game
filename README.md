# Pong Game

This project was built as a hands-on practice exercise to strengthen my understanding of object-oriented programming in Python — specifically class design, encapsulation, and how multiple objects (paddle, ball, scoreboard) interact in real time. It was a great way to apply OOP concepts beyond theory and see them work in a live, interactive application.

## Features
- Object-oriented design (paddle, ball, scoreboard classes)
- Collision detection
- Score tracking

## How to run
1. Clone this repo
2. Run `python main.py`

## Controls
- Right paddle: Up / Down arrow keys
- Left paddle: W / S keys
